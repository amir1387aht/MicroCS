# Standard library reference

> [!NOTE]
> Generated by `python3 tools/gen_stdlib_doc.py` from the native registration tables in
> `src/` and `modules/` — this is exactly what a script can call. `·` = one argument,
> `…` = variable argument count (overloads are resolved at run time).

Behaviour follows .NET wherever the member exists there. Deliberate differences are listed
in [LANGUAGE.md](LANGUAGE.md#deliberate-microcs-behaviour-differs-from-net). Library groups can
be removed per VM with `cfg.stdlib` and at build time with the `MCS_ENABLE_*` flags in
`include/mcs_config.h`.

LINQ operators are *eager*: each returns a new `List<T>` (or a scalar) immediately.
They are available directly on arrays, `List<T>`, `Dictionary`, `HashSet`, `Stack`, `Queue` and
the results of other operators. Building with `MCS_ENABLE_LINQ=0` removes them (and `Enumerable`)
to save ~12 KB of flash; `List<T>` methods such as `Find`, `ForEach`, `Exists`, `ConvertAll` stay.
