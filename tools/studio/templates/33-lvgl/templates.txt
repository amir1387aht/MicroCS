category: LVGL (host GUI)
requires: Lvgl

[button.cs] Host-owned LVGL button
save as: main.cs
Requires an already initialized and attached native LVGL environment with Label and Button enabled. The host owns rendering and ticks; this template starts no display or GUI loop.

[assets.cs] LVGL fonts and images from a host filesystem
save as: main.cs
Requires the host to register LVGL drive S: and provide /fonts/ui.fnt and /images/logo.bin converted for its LVGL version/configuration. Can use the bounded native MicroCS VFS adapter; no script filesystem initialization or display loop is added. Missing assets are reported and the panel is disposed.

[native-api.cs] Checked native LVGL APIs and extended slider range
save as: main.cs
Uses the generated native-call allowlist, cached build-specific API IDs, scalar styles, native constants and queued value events. The host must attach LVGL with Label and Slider. No raw pointers, native initialization or GUI loop is exposed.

[grid-line.cs] Copied LVGL Grid tracks and Line points
save as: main.cs
Requires host attachment with Grid and Line enabled. Uses bounded native copies of track/point arrays, explicit fractional tracks and checked cell placement; VM mutations and GC cannot invalidate native drawing data. The host owns rendering and synchronization.
