category: LVGL (host GUI)
requires: Lvgl

[button.cs] Host-owned LVGL button
save as: main.cs
Requires an already initialized and attached native LVGL environment with Label and Button enabled. The host owns rendering and ticks; this template starts no display or GUI loop.

[assets.cs] LVGL fonts and images from a host filesystem
save as: main.cs
Requires the host to register LVGL drive S: and provide /fonts/ui.fnt and /images/logo.bin converted for its LVGL version/configuration. Can use the bounded native MicroCS VFS adapter; no script filesystem initialization or display loop is added. Missing assets are reported and the panel is disposed.
