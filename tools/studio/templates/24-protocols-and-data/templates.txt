# MicroCS Studio templates (Templates / Alt+T). One block per file, in the order Studio lists them:
#   [file] Display name   - a file in this folder
#   save as: name.cs      - optional: the name Studio suggests (default: the file name)
#   description lines     - shown in the list and the preview
category: Protocols and data

[crc.cs] CRC-8 / CRC-16 / CRC-32
Checksums used by sensors (CRC-8), Modbus (CRC-16) and files (CRC-32).

[modbus.cs] Modbus RTU master (read registers)
Build a Modbus RTU request, send it on a UART (RS-485) and parse the reply.

[nmea.cs] NMEA checksum and fields
Validate an NMEA sentence and pick out the fields.

[base64.cs] Base64 and hex encoding
Encode / decode Base64 and hex strings by hand.

[commands.cs] Command interpreter on the console
Parse typed commands (led on, pwm 50, help) - a device CLI.

[json_out.cs] JSON-style output (manual)
Build JSON text for a host program or MQTT bridge.

[ringbuffer.cs] Ring buffer (circular queue)
A fixed-size buffer for samples - no allocation per sample.
