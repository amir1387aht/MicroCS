category: Fun and games

[morse.cs] Morse code blinker
Blink any text in Morse code on the LED (and print it).

[reaction.cs] Reaction time game
LED turns on after a random delay - press the button as fast as you can.

[dice.cs] Dice roller with LEDs
Roll a die on a button press and show it on 7 LEDs (or the console).

[life.cs] Conway's Game of Life
Cellular automaton on a 16x16 grid printed to the console.

[guess.cs] Guess the number
Console game: find the secret number 1..100 in as few guesses as you can.

[rps.cs] Rock, paper, scissors
Console game: best of five against the board.

[tictactoe.cs] Tic-tac-toe
Console game: play X against a simple computer O (cells 1-9).

[hangman.cs] Hangman
Console game: guess the hidden word one letter at a time.
